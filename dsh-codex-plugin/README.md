# dsh Web 的 Codex 会话窗

鼠标移到右上方的灰色叠窗图标，或用 Tab 聚焦，可查看功能介绍、连接状态和已绑定会话的运行及待审批数量。点击图标打开 Codex 会话窗。窗口默认铺满浏览器视口。关闭窗口或按 Esc 回到原来的 dsh 页面。插件在 Web 和桌面壳共用同一套实现。

## 会话阅读与操作

- 绑定列表使用 Codex 侧栏「最近」的活动时间（recencyAt）倒序排列，每行显示会话标题、项目目录名和最近活动时间。旧记录缺少活动时间时使用更新时间。输入标题、项目路径或会话 ID 可搜索，空格分隔的关键词会同时匹配。搜索会继续查找更早的会话，也可以手动加载下一页。
- 首次打开时优先显示最多四个已加载的会话。左上角「Codex 会话窗」管理绑定，标题栏的标签管理显示。每个会话窗最多绑定八个会话，同时最多展示四张卡片。标题较长或空间不足时，标签自动收窄，悬停可查看完整标题，点击标签右侧的 × 可取消绑定。满四屏时，新绑定的会话留在标题栏。点击它的标签会替换最早显示的卡片。浏览器记住绑定和显示组合。
- 单屏或放大一张卡片时，消息、执行过程、审批和输入框共用一条居中阅读栏，最大宽度为 46rem（默认字号下为 736 像素）。再次点击卡片的放大按钮恢复并排阅读。
- 运行中的标签整面显示流动渐变，卡片标题下方保留细线。待审批的标签带有琥珀色渐变和感叹号，切到后台仍然可见。系统启用减少动态效果时使用静态提示。
- 每轮中，你的发言显示为靠右的浅蓝气泡，Codex 的最终回复靠左，主对话和阶段说明支持 Markdown 表格、代码块、嵌套列表、图片、Emoji 短码、引用链接和自动链接。工作区内的文件链接和相对图片地址按对应会话的工作目录解析。
- 悬停或用键盘聚焦消息，可查看本地时间和复制原文。空闲时可在原位置编辑每轮的首条用户消息。发送后 Codex 回退到该轮之前，保留附件并以新文本重新生成。工作区文件保留已有改动。
- 点击 HTML 文件链接可在会话内运行交互预览，支持内联脚本及本地脚本、样式表和图片。Markdown 文件按标题、列表、表格、代码和链接排版，文档内相对路径以该文档为基准。普通图片链接点击后打开大图，显式嵌入的图片与可读取的图片附件随消息展示。按 Esc 返回。源码和其他 UTF-8 文本在窗内按原文展示。PDF 使用浏览器自带阅读器，音视频使用播放控件。其余二进制文件显示文件信息，可按需点击「保存文件」。
- 正在运行的轮次只显示一行最新进度，点击展开或收起。阶段说明、工具调用、命令输出和文件变更显示在缩进线内。用时和该轮回复共用一块局部衬底，时间及消息操作使用独立衬底。结束后自动折叠，可点击「用时」或「执行详情」回看。中断和失败的轮次保留状态。历史会话打开时直接显示主对话。
- 顶栏的图片按钮用于管理背景图库。图库在当前浏览器保存最多 8 张图片，按会话自动分配，图片较少时循环使用。拖动缩略图可调整分配顺序，遮罩滑块可在 0% 到 100% 之间实时调整。两项设置保存在当前浏览器。新图库内置三张鲸鱼娘插画，可逐张移除。
- 拖动顶部标签或卡片标题，可以调整会话顺序。聚焦标签后也可按 Alt + 左右方向键移动。排序会随绑定组合保存，卡片和标签使用同一顺序。标题并排显示模型名称和推理档位，Fast 开启时在名称前显示闪电图标。模型栏只读，会话状态由圆点表示。
- 输入框的回形针支持选图，也可以粘贴或拖入图片。可以单发图片或随文字发送，支持 PNG、JPEG、WebP、GIF，每条消息图片合计最多 16 MiB。
- 每张卡片单独滚动。输入后按 Enter 发送，Shift+Enter 换行。运行中的会话接收追加指令，空闲会话开启新一轮。命令执行或文件修改需要审批时，按钮出现在对应卡片输入框上方。
- 交互预览使用本地示例。可在运行中的示例追加指令，或处理文件修改审批，观察执行区自动收起。preview.html 可直接在浏览器中打开。

## 接入方式

dsh 浏览器插件在全局 `shell.overlay` 注册单个悬浮栏，通过原生 HTML dialog 显示会话窗。聚焦、切换和隐藏卡片均保留已绑定会话的订阅，输入草稿在本次工作台内按会话保存。

Host 使用 dsh 已认证的 `/api/codex-wall` 精确 POST 路由，仅接受 owner peer。每个打开的工作台通过独立的 WebSocket 加入 Desktop 的 app-server。macOS 使用 Unix socket，Windows 按 CODEX_PROXY_SOCKET_PATH 接入本机 proxy 的 socket，proxy 与 app-server 之间使用带令牌认证的回环连接。目录读取当前账号最近最多 100 条交互线程，再筛选 Desktop 来源，并按 ID 补查已保存的绑定。打开会话时读取最近 12 轮的摘要，并补齐正在运行轮次的最近 60 项记录。历史轮次的执行记录在展开时按需读取最近 60 项。执行细节单项显示最多 16000 个字符，命令输出保留末尾 3000 个字符。

工作台按 turnId 和 itemId 归并消息，按回复的 phase 区分阶段说明和最终回答。旧记录缺少 phase 时，已结束轮次的最后一条无阶段回复作为主回复。页面每 650 毫秒检查版本。有变化时仅传输在屏会话的正文，其余已绑定会话传输标题和状态。发送和审批绑定所在会话，关闭窗口后释放该工作台的连接。

## 安装与配置

预构建包的手动安装步骤见 [macOS 安装说明](../codex-proxy/mac/README.md)和 [Windows 安装说明](../codex-proxy/windows/README.md)。将对应架构的 proxy 和整个插件目录放在选定位置，在用户环境变量中设置 CODEX_CLI_PATH、CODEX_PROXY_REAL_CODEX、CODEX_PROXY_SOCKET_PATH。重新启动 Desktop 与 dsh Web 后，插件会使用该 socket 文件地址。

从源码安装时，在本目录运行 `make deps`。修改 src 下的界面源码后运行 `make build`，更新插件和离线预览共用的 client.js。在 dsh Web 的「插件 → 添加插件方式 → 安装第三方插件」中输入本目录的绝对路径，安装并启用。链接安装依赖本目录及其 node_modules。

macOS 同样支持以 `CODEX_PROXY_SOCKET_PATH` 指定完整 socket 文件路径。原目录配置下插件默认使用 `~/data/codex/socket/app.sock`。其他位置可在 dsh 宿主环境设置 `CODEX_PROXY_SOCKET_DIR`，或在目标 profile 的 cordis.patch.yml 中指定完整地址。

```yaml
- id: codex-multiscreen
  name: dsh-codex-plugin
  config:
    socketPath: /absolute/path/to/app.sock
```

代理配置见 [codex-proxy 说明](../codex-proxy/README.md)。运行 `make test` 验证本机协议交互。

单独分发插件时，运行 `make package` 生成 `bin/dsh-codex-plugin.zip`，包含 Web 插件及运行时依赖。
